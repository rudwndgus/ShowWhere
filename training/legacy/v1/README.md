# 과거의 안내에서 배우는 이유

> `ai-learning` 브랜치는 이전의 교정 경험을 버리지 않되, 더 나은 의미 중심의 배움으로 발전시키는 공간입니다.

ShowWhere의 초기 안내는 화면 위치와 당시 환경에 더 많이 의존했습니다. 그 기록들은 완벽한 정답은 아니지만, 사용자가 어디에서 어려움을 겪었고 어떤 안내가 부족했는지를 보여주는 소중한 역사입니다.

## 과거 기록이 알려준 것

화면 위치만 기억해서는 다른 컴퓨터와 다른 화면에서 같은 도움을 줄 수 없었습니다. 한 번 맞았던 위치가 다음에는 틀릴 수 있었고, 사용자의 진짜 목적을 이해하지 못하면 올바른 버튼처럼 보이는 잘못된 선택을 계속 추천할 수 있었습니다.

이 경험은 ShowWhere가 좌표가 아닌 의미를 배워야 한다는 방향을 분명하게 만들었습니다.

## 과거를 그대로 정답으로 삼지 않습니다

이전의 교정은 참고할 수 있지만 자동으로 새로운 정답이 되지는 않습니다. 당시의 질문과 상황에서 유용한 의미를 찾아내고, 현재의 기준으로 다시 검토한 뒤, 사람이 옳다고 확인한 내용만 신뢰할 수 있는 배움으로 이어져야 합니다.

## 우리가 지키려는 태도

과거 기록을 없애서 실수를 감추지 않습니다. 그렇다고 검증되지 않은 기록을 그대로 믿지도 않습니다.

ShowWhere는 이전의 실패와 교정을 안전하게 돌아보고, 그 경험을 더 정확하고 더 사람다운 안내로 바꾸어 나가고자 합니다.
