# ShowWhere

> **Don't explain your screen. Just tell us your goal.**

ShowWhere는 사용자가 화면을 설명하지 않아도, 하고 싶은 일만 말하면 **다음에 눌러야 할 위치를 화면 위에 직접 보여주는 Windows 안내 도우미**입니다.

## 왜 ShowWhere인가요?

기술 지원에서 가장 오래 걸리는 순간은 문제 해결 자체보다 버튼의 위치를 설명할 때가 많습니다.

> “설정을 눌러주세요.”
>
> “설정이 어디 있나요?”
>
> “오른쪽 위 톱니바퀴입니다.”
>
> “안 보여요.”

ShowWhere는 말로 위치를 설명하는 대신 사용자의 화면에서 정확한 다음 위치를 표시합니다. 사용자는 인터페이스를 외울 필요 없이 자신이 끝내고 싶은 일에 집중할 수 있습니다.

## 사용 방법

1. 위의 다운로드 버튼으로 `ShowWhere.exe`를 받습니다.
2. EXE를 실행하고 화면에 나타난 고릴라를 누릅니다.
3. “아마존에서 로그인 어디서 해?”, “프린터 설정을 확인하고 싶어”처럼 목표를 입력합니다.
4. ShowWhere가 표시한 위치를 누르면 다음 단계를 이어서 안내합니다.

ShowWhere는 사용자를 대신해 자동 클릭하지 않습니다. 종료하려면 고릴라를 **마우스 오른쪽 버튼으로 클릭한 뒤 `종료`**를 선택하세요. 여러 번 실행해도 한 개만 실행됩니다.

> 인터넷 연결과 ShowWhere 안내 서버가 필요합니다. 서명되지 않은 시험 배포본에서는 Windows SmartScreen 경고가 나타날 수 있습니다.

## 우리가 바라는 미래

ShowWhere의 목표는 단순한 버튼 검색이 아닙니다. 로그인, 설정 변경, 문제 해결처럼 여러 화면을 거치는 작업에서도 사용자가 목표에 도달할 때까지 한 단계씩 함께 이동하고, 도착하면 멈출 줄 아는 범용 인터페이스 내비게이션 도우미를 지향합니다.

궁극적으로는 Windows뿐 아니라 Android, macOS와 다양한 업무용 프로그램에서도 같은 방식으로 도움을 받을 수 있는, 누구에게나 친근한 디지털 길잡이를 만들고자 합니다.

## 브랜치 안내

- `main`: ShowWhere의 공식 소개와 안정된 결과물을 보여주는 간판 브랜치
- `ShowWhere2.0`: Windows 앱, AI 안내 서버와 배포 기능을 통합해 개발하는 브랜치
- `UI`: 사용자 화면과 인터랙션을 집중적으로 다듬는 브랜치
- `ai-learning`: 개발자 피드백, 라벨링과 학습 데이터 품질을 발전시키는 브랜치
- `window-back-kyung`: Windows 안내 동작을 실험하고 개선하는 브랜치
